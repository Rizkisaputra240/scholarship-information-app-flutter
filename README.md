# Aplikasi Informasi Beasiswa - Flutter & Firebase

Aplikasi informasi dan pendaftaran beasiswa yang dikembangkan menggunakan Flutter dan Firebase.

## Fitur

- Registrasi akun pengguna
- Login menggunakan Firebase Authentication
- Menampilkan daftar informasi beasiswa
- Menampilkan detail dan persyaratan beasiswa
- Pendaftaran beasiswa
- Menampilkan profil pengguna
- Menampilkan beasiswa yang telah didaftarkan
- Logout pengguna

## Teknologi

- Flutter
- Dart
- Firebase Authentication
- Firebase Realtime Database
- Provider
- GetX
- Lottie

## Firebase

Aplikasi menggunakan Firebase untuk:

- Autentikasi pengguna
- Penyimpanan data pengguna
- Penyimpanan data pendaftaran beasiswa

## Tentang Project

Project ini dikembangkan sebagai tugas UAS mata kuliah Pemrograman Mobile di Universitas Duta Bangsa Surakarta tahun akademik 2023/2024.
